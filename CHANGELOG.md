# Журнал изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по SemVer.
Каждое изменение попадает сюда и в затронутые файлы `docs/`.

## [2.1.0] — 2026-11-09

### Интерфейс
- **Двухпанельный вход**: слева бренд и описание, справа форма; крупнее поля.
- **Настройки с вкладками сверху** (Основные, Подписка, Голос, Окно, Обновления,
  Данные) и поиском, который переключает на нужный раздел.
- **Эмодзи-пикер** с поиском по названиям; архитектура `EmojiCatalog` готова к
  добавлению кастомных паков.
- **Drag-and-drop** файлов в поле ввода и **превью вложений** до отправки
  (чипы с именем и удалением).
- Анимация появления нового сообщения и настройка «Анимации интерфейса».
- Кнопка «Ответить» при наведении на сообщение, стили цитаты, панель ответа над
  полем ввода.

### Сообщения
- **Ответы (reply)**: миграция БД **v6** (`messages.reply_to_id`,
  `outbox.reply_to_id`), необязательное поле `reply_to` в `msg.send`; сервер
  проверяет, что оригинал из того же чата.
- Цитата показывает имя и фрагмент, для вложений — «Вложение».
- **Статусы**: отправлено `✓`, доставлено `✓✓`, прочитано `✓✓` акцентным цветом.

### Скрипты
- `scripts/publish-update.ps1`: манифест → проверка хешей → tar.gz → scp →
  опционально установка по SSH.
- `scripts/deploy-update.sh`: распаковка, проверка хешей, staging, атомарная
  подмена каталога обновлений, откат при ошибке.

### Тесты
- `tst_message_ops::replyIsStoredAndValidated`: ответ сохраняется, ссылка на
  несуществующее сообщение отклоняется.
- Всего 23 набора, все зелёные.

## [2.0.2] — 2026-11-08

### Исправлено
- Второй запуск клиента больше не создаёт вторую иконку в трее: он активирует уже
  запущенное окно (локальный сокет), а не показывает сообщение об ошибке.
- Updater после копирования проверяет, что клиент действительно запустился
  (лог `%TEMP%\MessengerUpdater.log` с кодом завершения), а клиент убирает иконку
  из трея перед выходом — «призрачные» иконки больше не остаются.

### Голос
- **Таймаут вызова 30 секунд**: вызывающий видит «Абонент не ответил», у
  вызываемого — «Пропущенный вызов от …».
- **Занято**: если вызываемый уже в звонке, он автоматически отклоняет вызов с
  причиной, вызывающий видит «Абонент уже в другом звонке». Сервер не даёт
  состоять в двух голосовых комнатах одновременно.
- В карточке профиля (личный чат) появилась кнопка **«Позвонить»**.
- Отклонение вызова передаёт причину (`reason`) — `busy`, `timeout` или пусто.

## [2.0.1] — 2026-11-08

### Исправлено
- **После обновления клиент не перезапускался**: updater пытался заменить сам себя
  (`MessengerUpdater.exe` заблокирован) и завершался с ошибкой. Теперь он
  запускается из копии `MessengerUpdater.new.exe`, пишет лог
  `%TEMP%\MessengerUpdater.log`, показывает сообщение при ошибке и перезапускает
  клиент через `startDetached`, а при необходимости — через `ShellExecute`.
- Запуск updater из неустановленного клиента: если нужен UAC, используется
  `ShellExecute runas`.
- Для перехода **2.0.0 → 2.0.1** манифест не содержит `MessengerUpdater.exe`:
  иначе старый updater снова упёрся бы в собственный заблокированный файл.
  Новый updater попадёт при следующем обновлении или установке 2.0.1.

### Добавлено
- **Трей**: крестик сворачивает окно в трей, двойной клик открывает, в меню —
  «Открыть», «Проверить обновления», «Выход». Настройка «Сворачивать в трей при
  закрытии» (по умолчанию включена).
- **Автопроверка обновлений**: через 3 секунды после входа, затем каждые 6 часов
  и после переподключения; уведомление в трее о новой версии.

## [2.0.0] — 2026-11-08

### Безопасность голоса
- **UDP-звук шифруется AES-256-GCM** (OpenSSL EVP). Сервер — только релей и
  ключей не видит; ключ комнаты выдаётся по TLS в `voice.join` (`voice_key`).
- Защита от повторов: сервер и клиент отбрасывают пакеты с неподрастающим `seq`;
  nonce выводится из `seq`, подмена тега отклоняется.
- Jitter-буфер ключуется парой `(user_id, seq)` — несколько говорящих больше не
  конфликтуют по номерам пакетов.
- Новый формат UDP-пакета `MV02`; клиент и сервер нужно обновить вместе.

### Голос
- **Push-to-talk**: Настройки → Голос → «Push-to-talk», в шапке появляется
  кнопка «Говорить» (передача только при удержании).
- Выбор **микрофона и динамиков** в настройках; при недоступности — системные.

### Документация
- `docs/VOICE-SECURITY.md`: ключи, формат пакета, защита от повторов, ограничения.

### Тесты
- `tst_voice_crypto`: шифрование/расшифровка, подмена тега, чужой seq.
- `tst_voice_udp`: оба участника получают одинаковый ключ комнаты.

## [1.9.0] — 2026-11-08

### Проверено

## [1.8.0] — 2026-11-08

### Добавлено
- **Автообновление**: сервер раздаёт `manifest.json` и файлы; клиент сравнивает
  sha256, скачивает только изменённые файлы и **докачивает** недокачанное
  (`update.download` с `offset`).
- `MessengerUpdater.exe`: ждёт выхода клиента, сохраняет бэкап, заменяет файлы,
  запускает приложение; манифест `requireAdministrator` (UAC) для `Program Files`.
- Настройки → **Обновления**: проверка, размер обновления, прогресс, установка;
  автопроверка через 8 секунд после входа.
- Скрипты: `scripts/make-manifest.ps1` (манифест по каталогу),
  `scripts/sign.ps1` (подпись exe и установщика, PFX или отпечаток).
- Сервер: `--updates-dir`, `update.manifest`, `update.download` (с защитой от
  выхода за каталог).
- `docs/UPDATER.md` — манифест, дельта, применение, откат, подпись.

### Ограничение
- Подпись «проверенного издателя» требует сертификата подписи кода от доверенного
  УЦ; самоподписанный сертификат только для внутренних тестов.

### Тесты
- `tst_update`: манифест, докачка файла с середины (сверка байтов), отказ на
  `../server.db`.

## [1.7.1] — 2026-11-08

### Добавлено
- Индикатор «говорит»: клиент считает уровень микрофона, отправляет
  `voice.speaking`, сервер рассылает `ev.voice.speaking`; в шапке чата

### Тесты

## [1.7.0] — 2026-11-08

### Добавлено
- **Вызовы**: «Голос» теперь звонит. Сигнализация `voice.invite`, `voice.accept`,
  `voice.decline`, `voice.cancel`; у собеседника окно «Принять / Отклонить»,
  у звонящего статус «Звоним…» и кнопка «Отменить».
- **UDP-транспорт**: `voice.join` выдаёт `udp_port` и `udp_token`; звук идёт
  дейтаграммами через сервер, а не по TCP. Сервер запоминает адрес клиента
  по первому пакету (работает за NAT).
- **Джиттер-буфер** на клиенте: переупорядочивание по seq, выдача по 20 мс,
  ограничение очереди, keepalive каждые 5 секунд.
- `deploy-vps.sh` открывает UDP-порт `45001` в `ufw`.

### Тесты
- `tst_voice_call`: приглашение, принятие, отклонение, отмена.
- `tst_voice_udp`: дейтаграмма доходит до второго участника с его `user_id`,
  отправитель не получает свой кадр.

## [1.6.1] — 2026-11-08

- Сообщение об ошибке загрузки Opus теперь содержит причину от `QLibrary`.

### Тесты
- `tst_opus` дополнительно проверяет загрузку библиотеки из каталога приложения.

## [1.6.0] — 2026-11-08

### Добавлено
- Голосовой канал в любом чате (личном и группе): кнопка «Голос» в шапке.
- Захват микрофона и воспроизведение через QtMultimedia (48 кГц, моно, 16 бит),
  кодек **Opus** (libopus.dll загружается динамически, в комплекте).
- Передача голоса через сервер: `voice.join`/`voice.leave`, кадры `type=3`,
  событие `ev.voice`; сервер пересылает звук остальным участникам комнаты.
- Кнопка «Микрофон» (mute) и статус «Голос: в эфире» в шапке.
- Третий тип кадра в протоколе и тест `tst_voice_relay` (релей, выход из комнаты).
- Тест `tst_opus`: кодирование/декодирование 20 мс кадра и PLC при потере пакета.

### Ограничения
- Голос идёт по существующему TCP-соединению (TLS), а не UDP: на плохой сети
  возможны задержки из-за повторной передачи. UDP-транспорт — следующий этап.
