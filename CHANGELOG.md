# Журнал изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по SemVer.
Каждое изменение попадает сюда и в затронутые файлы `docs/`.

## [1.3.0] — 2026-11-08

### Добавлено
- Редактирование своих текстовых сообщений: правый клик → «Изменить»,
  у сообщения появляется пометка «изм.», остальные участники видят событие
  `ev.msg.edited`.
- Удаление сообщений: «Удалить у всех» (только свои, tombstone «Сообщение удалено»,
  событие `ev.msg.deleted`) и «Удалить у себя» (локально, запоминается в профиле).
- Копирование текста сообщения из контекстного меню.
- Схема БД v3: `messages.deleted`, `messages.edited_at`.
- Протокол: `msg.edit`, `msg.delete`, события `ev.msg.edited`, `ev.msg.deleted`
  (описано в `docs/protocol.md`).
- `docs/UI-CONCEPTS.md`: панель участников по присланному макету и концепция
  кастомизации личной странички за подписку.

### Тесты
- `tst_message_ops`: редактирование и удаление доходят до второго клиента,
  чужие сообщения менять нельзя, история отдаёт tombstone.

## [1.2.0] — 2026-11-08

### Добавлено
- Удаление чата из списка: правый клик по чату → «Удалить чат». Чат скрывается,
  локальная история и вложения удаляются; у собеседника сообщения остаются.
  Новое сообщение возвращает чат в список.
- Очистка истории чата: правый клик → «Очистить историю» (локально, чат остаётся).
- Скрытые чаты хранятся в профиле (`settings.ini`, ключ `chats/hidden`).

### Документация
- `CHANGELOG.md`, `docs/FEATURES.md` (матрица функций), `docs/VOICE-AND-SUBSCRIPTIONS.md`
  (план голосовых каналов и подписок).

### Тесты
- `tst_settings`: сохранение списка скрытых чатов.

## [1.1.1] — 2026-11-08

### Исправлено
- Вложения из истории теперь скачиваются при открытии чата (раньше «Загрузка…» висела вечно).
- Таймаут скачивания 90 секунд, автоматические повторы, ручной повтор по клику.
- После обрыва связи «зависшие» загрузки очищаются и повторяются при переподключении.
- Отправитель получает метаданные своего вложения (id, sha256, размер).

### Добавлено
- `messenger.ini` рядом с клиентом задаёт сервер по умолчанию (host/port/tls).
- Автовход по сохранённой сессии при повторном показе окна входа.

### Тесты
- `tst_attachment_history`: отправка вложения, «перезапуск» клиента, скачивание из истории.

## [1.1.0] — 2026-11-08

### Добавлено
- TLS: `QSslSocket` на клиенте и сервере, самоподписанный сертификат,
  закрепление SHA-256 отпечатка (TOFU), отказ при подмене.
- Служба Windows: `--install-service`, `--uninstall-service`, режим `--service`.
- Развёртывание на VPS: `scripts/deploy-vps.sh`, `docs/VPS-DEPLOY.md`.
- Установщик Inno Setup: ярлыки, правило брандмауэра, установка службы.
- OpenSSL 1.1.1w в комплекте (нужен Qt 5.14 для TLS).

### Тесты
- `tst_tls`: handshake, закрепление отпечатка, отказ при несовпадении.

## [1.0.0] — 2026-11-08

### Добавлено
- Сервер: регистрация и вход (PBKDF2-HMAC-SHA256), общий и личные чаты,
  сообщения с `seq`, квитанции delivered/read, присутствие, «печатает…».
- Вложения через сервер: sha256, чанки, лимит 25 МБ, кэш на клиенте.
- Клиент: список чатов, лента с группировкой, композер, ленивая история,
  SQLite-история в рабочем потоке, офлайн-очередь, автопереподключение.
- Медиа: фото, GIF, видео, «Сохранить как…», лайтбокс.
- Темы, трей и уведомления, поиск, настройки, RU/EN.
- Портативный пакет Windows, CI для Windows и Ubuntu.
