# UI-концепции: участники групп и личная страничка

Документ фиксирует дизайн-решения по присланному макету. Код групп ещё не
написан; личная страничка — только концепция (по запросу «пока не начинай делать»).

## 1. Макет: список людей

На макете два экрана:

- **слева** — список людей: аватар, имя, вторая строка (статус/время),
  поиск «Online Names», шеврон у строки, нижняя панель действий;
- **справа** — «Compiner Lists»: список участников с аватарами, подписями,
  счётчиками/временем, закреплённые сверху, поиск и меню.

Это ровно то, что нужно для **панели участников группового чата**.

### Как переносим в приложение

| Элемент макета | Где используем |
|---|---|
| Строка участника (аватар, имя, статус) | панель «Участники» в групповом чате |
| Вторая строка (онлайн/был(а), роль) | статус присутствия + роль |
| Поиск по именам | фильтр участников |
| Шеврон/меню справа | действия: написать, назначить админом, исключить |
| Закреплённые сверху | владелец и администраторы |
| Счётчик/время справа | «в сети», «был(а) 12:39» |

### Визуальные токены (в духе макета)

- фон карточки: тёмный сине-серый (`#232838`), радиус 16, мягкая тень;
- строка 56 px, аватар 40 px, имя 14–15 px semibold;
- вторичный текст приглушённый (`#8A93A6`);
- выделение строки — акцентный синий с прозрачностью 12 %;
- онлайн — зелёная точка 8 px в правом нижнем углу аватара.

Токены кладём в QSS-тему (`BubbleOther`, `Sidebar`, отдельные `ParticipantRow`),
чтобы работало и в светлой теме.

### Где размещать панель

1. **Групповой чат** — кнопка «Участники» в шапке открывает правую панель
   (на узком окне — диалог). Ширина 280–320 px, скролл, поиск сверху.
2. **Создание группы** — тот же список с чекбоксами и поиском.
3. **Контакты** (позже) — тот же компонент, переиспользуемый.

## 2. Групповые чаты: UX-каркас

- **Создание**: «+» → «Новая группа» → название, аватар (цвет/эмодзи),
  выбор участников из списка, «Создать».
- **Шапка группы**: аватар, название, «N участников», кнопка «Участники».
- **Роли**: владелец, администратор, участник. Владелец назначает админов,
  исключает, переименовывает; админ исключает участников и закрепляет сообщения.
- **Выход**: «Покинуть группу» в меню; владелец передаёт права или группа
  остаётся без владельца (решение: владелец обязан передать права).
- **Системные сообщения**: «Аня создала группу», «Борис добавлен», «Вышел».
  Реализуются как сообщения `kind=text` от системного пользователя или
  отдельным типом (решим при реализации).

## 3. Личная страничка за подписку (концепция)

Цель: человек с подпиской делает профиль «своим», но это не ломает читаемость чата.

### Что настраивается

| Элемент | Бесплатно | Подписка |
|---|---|---|
| Аватар | да | да |
| Баннер профиля (градиент/картинка) | нет | да |
| Рамка аватара (стили) | нет | да |
| Акцентный цвет профиля | 6 базовых | палитра + свой HEX |
| Бейджи (подписка, роль, достижения) | базовые | коллекция |
| Короткое «о себе» | нет | да (до 200 символов) |
| Статус (эмодзи + текст) | нет | да |
| Фон профиля в карточке контакта | нет | да |

### Где показывается

- **Карточка профиля** — открывается по клику на аватар/имя в чате:
  баннер сверху, аватар с рамкой, имя, статус, «о себе», бейджи,
  кнопки «Написать» / «Закрыть».
- **Список чатов/участников** — только аватар с рамкой и точка статуса,
  чтобы не перегружать список.

### Модель данных (на будущее)

- `profiles`: `user_id`, `banner_kind`, `banner_value`, `accent`, `bio`,
  `status_emoji`, `status_text`, `frame_id`, `badges`.
- `entitlements`: `frame`, `banner`, `accent_custom`, `badges`, `bio`.
- Пакеты оформления — те же «паки», что и темы: манифест + ассеты,
  проверка права на сервере при выдаче.

### Ограничения

- изображения баннера ≤ 2 МБ, кроп 16:9 на клиенте;
- модерация текста «о себе» и статуса — общая проверка `security::checkMessageText`;
- всё оформление — только визуальное: не влияет на права и не даёт преимуществ
  в чате (кроме бейджа подписки).

### Этапы

1. Карточка профиля (без кастомизации) — 2–3 дня.
2. Баннер + акцент + «о себе» + статус — 1 неделя.
3. Рамки и бейджи, проверка entitlements — 1 неделя.
4. Паки оформления и оплата — вместе с подпиской (см.
   `VOICE-AND-SUBSCRIPTIONS.md`).

## Реализовано в 2.1.0

- Двухпанельный вход: бренд слева, форма справа.
- Настройки: вкладки «Основные», «Подписка», «Голос», «Окно», «Обновления»,
  «Данные» + поиск по разделам.
- Композер: эмодзи-пикер, drag-and-drop, превью вложений, автовысота.
- Лента: ответы с цитатой, панель действия при наведении, статусы прочтения.
- Анимация появления нового сообщения (отключаемая).
