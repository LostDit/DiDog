# Дорожная карта DiDog

Статусы: `[x]` — готово и проверено, `[~]` — в работе, `[ ]` — не начато.

## Где мы сейчас

MVP завершён (этапы M0–M7 прежнего плана): мессенджер **DiDog** с аккаунтами, личными
и групповыми чатами, вложениями, ответами и статусами прочтения, голосовыми
звонками с шифрованием AES-256-GCM, подписками и промокодами, автообновлением
с дельтой файлов и новым интерфейсом «всё наверху». 23 набора тестов зелёные.

Цель следующих больших обновлений — превратить MVP в продукт: стабильность,
безопасность, производительность, монетизация и распространение.

## Масштабирование: готовые серверные решения

Наш сервер — один процесс на Qt (TCP + SQLite + UDP-релей). Этого хватает на
сотни одновременных пользователей, но нет HA и горизонтального масштабирования.
Кандидаты для замены/дополнения (все open-source):

- **Messaging**: ejabberd (XMPP, Erlang, промышленный), Prosody (Lua, лёгкий),
  Matrix Synapse/Dendrite/Conduit (федерация), Centrifugo (WebSocket-хаб).
- **Voice/SFU**: LiveKit (Go, WebRTC, E2EE), mediasoup (Node/C++), Janus (C),
  Jitsi (Java).
- **Готовые мессенджеры**: Mattermost, Rocket.Chat, Zulip — если нужен продукт
  «из коробки», а не свой протокол.

Практичный путь: оставить клиент и протокол, вынести голос на **LiveKit**
(SFU + E2EE), БД на PostgreSQL, несколько инстансов за балансировщиком с
Redis pub/sub. Оценка: 2–4 недели на пилот LiveKit, 1–2 месяца на миграцию БД.
## Технический долг (перманентно)

- Переименование артефактов: `MessengerClient.exe` → `DiDog.exe`, каталог данных
  `MessengerApp` → `DiDog`, служба `messengerapp` → `didog` — с миграцией
  настроек и истории.
- Обновление иконки у уже установленных клиентов (кэш иконок Windows).
- Рефакторинг `MainWindow` (файл больше 1300 строк).
- Покрытие тестами голосового тракта и обновления end-to-end.

## Определение «выхода из MVP»

MVP считается пройденным, когда одновременно:

1. **Стабильность**: uptime сервера 99,9% за месяц, ноль потерь сообщений при
   сбоях; клиент не падает в топ-10 сценариях (авторепорты это доказывают).
2. **Безопасность**: голос E2EE, 2FA, сессии, политика конфиденциальности.
3. **Производительность**: запуск < 2 с, лента 10 000 сообщений без лагов.
4. **Продукт**: реакции, пересылка, закрепление, поиск, панель звонка, онбординг.
5. **Монетизация**: минимум один платный тариф с автоматическим доступом.
6. **Распространение**: подписанные релизы для Windows и Linux, публичный лендинг.

После этого — полный ребрендинг артефактов (пункт 1 техдолга) и запуск как
полноценный продукт.
