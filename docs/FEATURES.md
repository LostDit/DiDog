# Функции и планы

Состояние функций относительно «как у других мессенджеров». ✅ — есть,
🚧 — в работе/следующий шаг, ⏳ — запланировано, ❔ — требует решения.

## Чаты

| Функция | Статус | Комментарий |
|---|---|---|
| Личные чаты | ✅ | создание по логину |
| Общий чат | ✅ | один на сервер |
| Удаление чата у себя | ✅ | 1.2.0: скрытие + удаление локальной истории, возвращается новым сообщением |
| Очистка истории | ✅ | 1.2.0: локально |
| Удаление чата у обоих | ⏳ | нужно серверное `chat.delete` и событие для собеседника |
| Групповые чаты | ✅ | 1.4.0: создание, участники, роли, выход; переименование/исключение — далее |
| Панель участников | ✅ | 1.9.0: справа в окне чата (Discord-style), поиск, роли |
| Карточка профиля | ✅ | 1.9.0: баннер, @логин, статус, «Написать» |
| Закрепление, архив, mute | ⏳ | локальные флаги + синхронизация |
| Метки «непрочитано», счётчики | ✅ | |
